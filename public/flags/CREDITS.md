# Flag sources

All 51 flag SVGs (50 states + DC) in this directory are U.S. state/DC
government works, sourced via [nibsbin/us-state-flags-svg](https://github.com/nibsbin/us-state-flags-svg)
(itself pulled from Wikimedia Commons, per that repo's README). State
flags are generally in the public domain as works of state government.
